## Noch offen

Im restlichen Seitenkörper (Unser Haus, Pädagogik, Team-Fotos usw.) stehen
weiterhin Platzhalter (`media-frame--placeholder`). Sobald echte Fotos
vorliegen, im jeweiligen HTML den Platzhalter-Block durch das auskommentierte
`<img>`-Tag direkt darüber ersetzen.

**Wichtig:** Für alle Fotos, auf denen Kinder zu erkennen sind, muss eine
schriftliche Einwilligung der Erziehungsberechtigten vorliegen. Bilder vor
dem Hochladen verkleinern (max. 1600 px Breite) und als WebP oder JPG
(Qualität ca. 80 %) speichern – das hält die Seite schnell.
